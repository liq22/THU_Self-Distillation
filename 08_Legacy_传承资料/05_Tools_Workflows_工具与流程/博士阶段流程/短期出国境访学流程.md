# 短期出国境访学流程（给师弟妹）

> 来源: OS 卡片，短期出国境访学经验沉淀
> 整理日期: 2026-07-09
> 适用范围: 清华大学博士生短期出国境访学（申请、派出、返校、报销全流程）

---

## 边界说明

短访材料包括申请、录取后手续、离校/返校、报销和总结报告。本页保留**流程和模板**，不上传邀请信、资助协议、报销表、外方导师评语或个人总结原件。

## 适合谁读

- 清华大学机械系（或相关方向）准备申请短期出国境访学基金、或已被录取准备派出的博士生。
- 第一次走短访流程、不清楚"从申请到报销分几步、每步要交什么"的人。

## 读完能做什么

- 拿到一条从"申请前判断 → 申请材料 → 录取后手续 → 访学期间记录 → 回校报到 → 报销与总结"的完整流程。
- 知道每个阶段要备哪些典型材料、有哪些注意点。
- 避开"研究计划与博士主线脱节、访学日志回国补写、票据/汇率/资助标准没单独核对"等常见坑。

## 前置条件

- 已有明确的访学目的地、外方导师与访学时段。
- 导师同意支持，且初步判断符合所申请基金的条件。

## 标准流程

### 流程总表

| 阶段 | 目标 | 典型材料 | 注意点 |
|---|---|---|---|
| 申请前 | 判断是否符合基金条件 | 申请指南、培养基金规定、邀请信要求 | 先确认时间长度、目的地和导师支持 |
| 申请材料 | 提交访学基金申请 | 研究计划、邀请信、申请自查表 | 研究计划要和博士主线一致 |
| 录取后 | 完成派出前手续 | 录取提示、出国境须知、资助协议 | 关注离校、保险、经费和变更规则 |
| 访学期间 | 记录工作和交流 | 访学日志、seminar 记录、合作进展 | 每周记录，避免回国后补写困难 |
| 回校报到 | 完成返校确认 | 临时离校/回校手续单 | 及时确认系统状态 |
| 报销与总结 | 完成经费和成果闭环 | 收支情况表、总结报告、外方导师评语 | 票据、汇率、资助标准要单独核对 |

### 总结报告模板

1. 访学背景：访问单位、研究方向和出访目的。
2. 主要工作：按时间或主题列出完成事项。
3. 学术交流：seminar、组会、合作讨论、课程或 workshop。
4. 研究收获：对博士主线的具体帮助。
5. 生活与适应：只写可共享经验，不记录私人细节。
6. 后续计划：论文、合作、数据、代码或回访安排。
7. 给后来者的建议：申请、出行、沟通、报销。

## 常见坑

| 坑 | 表现 | 解决办法 |
|---|---|---|
| 研究计划与博士主线脱节 | 计划写成独立项目，评审认为偏离培养目标 | 申请前确认计划紧扣博士主线，能说清"访学对论文的直接帮助" |
| 访学日志回国才补写 | 回国后记不清细节，总结报告空洞 | 访学期间每周记一次（工作、交流、合作进展） |
| 票据/汇率/资助标准没单独核对 | 报销时发现票据不全或超资助标准 | 出发前建票据与报销记录表，资助标准单独存档 |
| 离校/回校手续漏办 | 系统状态未更新，影响后续流程 | 回校后尽快完成报到，及时确认系统状态 |
| 行程变更未走变更流程 | 改派/延期未报批，报销受阻 | 录取后先确认变更规则，需要时及时申请 |

## 检查清单（录取后）

- [ ] 保存录取通知和资助标准。
- [ ] 确认是否需要改派、延期或变更行程。
- [ ] 完成离校/出国境相关手续。
- [ ] 建立票据与报销记录表。
- [ ] 与访问导师确认抵达、汇报和研究计划。
- [ ] 回校后尽快完成报到、总结报告和报销。
