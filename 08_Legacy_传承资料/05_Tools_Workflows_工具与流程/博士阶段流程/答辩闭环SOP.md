# 答辩闭环 SOP（给师弟妹）

> 来源: OS 卡片 `011_答辩闭环材料清单.md`（A0_毕业整理）
> 整理日期: 2026-07-09
> 适用范围: 清华大学机械系博士答辩当天材料与 PPT 准备

---

## 边界说明

这页是写给师弟妹的**答辩当天**准备 SOP：答辩 PPT 怎么收敛版本、答辩当天要带哪些材料、答辩后要补齐哪些签字件。

它和 [[毕业流程操作指南]] **分工不重叠**：
- [[毕业流程操作指南]] 管**整条主流程**：评阅 → 两次报批 → 答辩申请 → 申报学位 → 系统归档。
- **本页只管答辩当天**：当天演示的 PPT 版本选择 + 当天 / 答辩后要齐的材料。

签字扫描 / 申报表原件等敏感件，本页只写**类型与阶段**，原件在私有区。

---

## 适合谁读

- 即将进入答辩准备期（答辩前 1–2 周）的清华机械系博士生。
- 第一次走博士答辩流程、不知道"答辩当天到底要带什么、PPT 该用哪一版"的人。

## 读完能做什么

- 知道答辩 PPT 该保留哪几个版本、可以忽略哪几个。
- 知道答辩当天现场要交什么、答辩后还要补齐哪些签字件才算学位闭环。
- 避开"PPT 终版选错、签字件漏一份、阶段材料混装"三个最常见的坑。

## 前置条件

- 已通过评阅、完成第一次报批（评阅意见答复 + 论文修改）。
- 已提交答辩申请、答辩委员会已组建。
- 详见 [[毕业流程操作指南]] 的"第二次报批：答辩申请"之前的内容。

## 标准流程

### 1. 收敛答辩 PPT 版本

答辩 PPT 会经历"含视频大版本 → 精简主讲版本"的压缩迭代。准备期要做的不是留所有版本，而是**判定终版**。

- 主讲终版判据：体积合理（40–60 MB）+ 主讲时长压到 30 分钟内（页数 ~58）。
- 早期含视频的大版本（~114 MB）保留作**素材源**，但不作主讲版。
- 一天内多次微调的中间版（如 V4.1/4.2/4.3）可忽略，已被终版覆盖。
- 详细版本树与选择逻辑见 [[答辩PPT版本树]]。

### 2. 备齐答辩当天现场材料

现场要交到答辩委员会的材料（组织材料，**不记名单内容**）：

- 加盖分委会公章的答辩委员会成员名单
- 导师评语
- 汇总后的评阅意见
- 决议书草稿
- 答辩记录、出席名单、表决票

答辩程序、表决规则（全体 2/3 以上同意）见 [[毕业流程操作指南]]。

### 3. 答辩后补齐签字件，完成学位闭环

答辩通过 ≠ 学位授予。答辩后还要齐备 **6 类必备材料**，缺一不可授予学位，核心是：

- **答辩后学位论文修改说明（F 类）双件齐全**：F 类 PDF 扫描签字 + Word 内嵌签字版，缺一不算闭环。
- 博士生情况简介（G 类）、评审结果通知、评阅答复签字版等。
- 完整 6 类 checklist 见 [[答辩闭环材料SOP]]。

### 4. 录像归档与去向衔接

- 答辩录像 / 咨询录音归档见 [[答辩录像与咨询录音索引]]。
- 学位闭环后衔接博后进站，见 [[博后进站申请流程]]。

## 常见坑

| 坑 | 表现 | 解决办法 |
|---|---|---|
| PPT 终版选错 | 拿含视频的大版本主讲，现场超时 | 主讲版用"30 分钟压缩版"，不是体积最大的 |
| F 类只到一份 | 只交 PDF 扫描，漏 Word 内嵌签字版 | 闭环前逐项核对"双件齐全" |
| 阶段材料混装 | 评阅答复签字版（送审阶段）被当成答辩后修改说明 | 两份带不同阶段前缀分别归档 |
| 签字件误进公开仓 | 扫描 PDF 被当普通附件上传 git | 公开页只记类型，原件全部私有指针 |
| 最终论文版本不一致 | 答辩后改了论文，系统里没换最终版 | 修改说明与系统提交版同步换 |

## 检查清单

- [ ] 答辩 PPT 主讲终版已定（30 分钟内、体积合理）
- [ ] 答辩当天现场材料齐备（名单 / 评语 / 汇总意见 / 决议书草稿 / 记录 / 出席名单 / 表决票）
- [ ] 答辩后修改说明 F 类**双件齐全**（PDF 扫描 + Word 内嵌签字）
- [ ] 博士生情况简介（G 类）已就位
- [ ] 最终论文与系统提交版一致
- [ ] 6 类必备材料齐备 → 可申报学位
- [ ] 录像已归档
- [ ] 公开仓不含签字 / 扫描 / 评阅意见原件

## 示例

答辩 PPT 从含视频大版本（~114 MB）压到 30 分钟主讲压缩版（~38 MB，58 页），是"精简主讲"迭代的典型路径。判定终版时，一个早期版本因体积只有 ~256 KB 被识别为疑似损坏、降级为备份——异常小的文件不要直接当主版本。详见 [[答辩PPT版本树]]。
