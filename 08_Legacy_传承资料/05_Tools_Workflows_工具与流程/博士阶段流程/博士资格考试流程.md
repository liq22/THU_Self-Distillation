# 博士资格考试流程（给师弟妹）

> 来源: OS 卡片，博士资格考试准备经验沉淀
> 整理日期: 2026-07-09
> 适用范围: 清华大学机械系博士资格考试准备与汇报

---

## 边界说明

博士资格考试原始材料（题库原文、他人 PPT、个人路线图源文件等）已私有归档。本页只沉淀**可复用的准备流程、汇报结构和复盘经验**，不公开题库原文、他人材料、个人 PPT 原件或未授权参考材料。

## 适合谁读

- 清华大学机械系（或相关方向）即将进入博士资格考试准备期的博士生。
- 第一次走资格考试流程、不清楚"该准备什么材料、汇报 PPT 怎么搭、Q&A 怎么备"的人。

## 读完能做什么

- 拿到一条从"规则确认 → 方向定位 → 知识补齐 → 汇报准备 → 模拟问答 → 复盘归档"的完整准备路线。
- 知道资格考试汇报 PPT 该放哪几个模块、Q&A 要准备哪几类问题。
- 避开"把资格考试当成纯成果展示、套用别人研究叙事、路线图做得太晚"等常见坑。

## 前置条件

- 已确定博士研究方向与主线问题。
- 已拿到本年度资格考试的形式、题型、评价重点和时间安排（来自学院/系通知）。

## 标准流程

### 准备路线

| 阶段 | 目标 | 输出物 |
|---|---|---|
| 规则确认 | 弄清楚考试形式、题型、评价重点和时间安排 | 一页考试规则摘要 |
| 方向定位 | 把博士主线放到学科问题中说明 | 研究问题地图 |
| 知识补齐 | 复习题库和基础概念，补足方向外短板 | 错题/概念清单 |
| 汇报准备 | 形成 10-20 分钟可讲清楚的研究路线 | 汇报 PPT 大纲 |
| 模拟问答 | 准备为什么做、怎么验证、边界在哪里 | Q&A 表 |
| 复盘归档 | 记录真实问题和准备不足 | 经验教训 note |

### 汇报 PPT 建议结构

- 个人研究背景：用 1-2 页说明方向、问题和已有基础。
- 学科定位：说明研究问题属于哪个领域，和设计所/机械工程的关系是什么。
- 核心问题：把问题压缩成 2-3 个可回答的问题。
- 方法路线：解释技术路线，不堆公式和模型细节。
- 阶段成果：只呈现已经稳定的工作，不放未确认结论。
- 后续计划：说明博士阶段如何继续推进。
- 风险与边界：主动说明数据、验证、工程应用和理论解释的限制。

### Q&A 准备表

| 问题类型 | 准备方式 |
|---|---|
| 为什么选这个问题 | 从学科价值、工程需求、个人主线三层回答 |
| 和已有工作的区别 | 准备 3 篇最相关工作，说明差异不是口号 |
| 方法是否可靠 | 准备验证设计、消融逻辑、失败案例 |
| 数据和场景是否充分 | 说明数据来源、泛化限制和后续补充计划 |
| 博士阶段能否完成 | 拆成已完成、正在做、计划做三类 |

## 常见坑

| 坑 | 表现 | 解决办法 |
|---|---|---|
| 把资格考试当成纯成果展示 | 只罗列工作，不讲问题定义和推进能力 | 重点放在"能否独立定义问题并推进研究"，成果只是佐证 |
| 套用他人研究叙事 | 参考别人 PPT 时把对方的研究故事搬到自己身上 | 借鉴结构（页面顺序、节奏），不照搬内容与叙事 |
| 路线图做得太晚 | 临近考试才画路线，暴露问题定义不清 | 路线图尽早做，哪怕粗糙也能暴露问题定义、验证链条和时间安排的漏洞 |
| 题库复习停在背概念 | 知识点背了但答不上来 | 题库复习要服务于问答，把概念转成可回答的论证 |

## 抽象原则（复盘要点）

- 资格考试不是只展示成果，更重要的是展示"能否独立定义问题并推进研究"。
- 参考他人 PPT 的价值在结构，不在内容；不要把别人的研究叙事套到自己身上。
- 路线图应早做，哪怕粗糙，也能暴露问题定义不清、验证链条断裂和时间安排过满。
- 题库复习要服务于问答，不要停留在背概念。

## 检查清单

- [ ] 已拿到本年度考试规则（形式/题型/评价重点/时间）。
- [ ] 研究问题地图（学科定位）已成型。
- [ ] 方向外知识短板已列出，进入复习。
- [ ] 汇报 PPT 大纲按 7 模块搭好，主讲时长压到 10-20 分钟。
- [ ] Q&A 表覆盖"为什么做 / 区别 / 可靠性 / 数据充分性 / 可完成性"五类。
- [ ] 准备不足点已记录，留作下年复盘 note。
