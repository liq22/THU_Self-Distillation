# 申请与荣誉材料组织流程（给师弟妹）

> 来源: OS 卡片，水木学者/国家奖学金/青年人才项目等申请材料组织经验
> 整理日期: 2026-07-09
> 适用范围: 清华大学博士生奖学金、人才项目等申请材料组织

---

## 边界说明

用于整理水木学者、国家奖学金、青年人才项目等申请材料。本页保留**组织方法、材料清单和答辩模板**，不上传申请表原件、评分表、证明照片、推荐意见、论文 PDF 和个人证书扫描件。

## 适合谁读

- 清华大学机械系（或相关方向）准备申请奖学金、人才项目或荣誉称号、需要组织一大堆申请材料的博士生。
- 第一次走这类申请、不清楚"材料怎么分类、先备什么、答辩 PPT 怎么取舍"的人。

## 读完能做什么

- 拿到一张"基本申请 / 推荐·审核 / 学术成果 / 综合素质 / 支撑材料 / 答辩展示"的材料分类与处理表。
- 知道从"读评审办法 → 建成果台账 → 备可核验事实 → 写个人叙事 → 答辩取舍 → 复盘"的准备顺序。
- 避开"先写叙事后备事实、答辩 PPT 堆材料、成果全文 PDF 进公开仓"等常见坑。

## 前置条件

- 已确定目标申请项目（奖学金/人才项目/荣誉）。
- 已拿到该项目的评审办法（含评分项、硬性门槛、提交格式）。

## 标准流程

### 材料组织结构

| 类别 | 典型材料 | 建议处理 |
|---|---|---|
| 基本申请 | 申请表、个人简介、研究计划 | 原件私有，公开版提炼结构 |
| 推荐/审核 | 院系推荐意见、导师意见 | 不提交 |
| 学术成果 | 论文、专利、项目、会议 | 只提交成果索引，不提交全文 PDF |
| 综合素质 | 社会实践、体育、服务、荣誉 | 只保留脱敏条目 |
| 支撑材料 | 证书、通知、照片、网页截图 | 原件私有，公开版记录材料类型 |
| 答辩展示 | PPT、讲稿、Q&A | 提炼页结构和准备经验 |

### 准备流程

1. 先读评审办法，拆出评分项、硬性门槛和提交格式。
2. 建一张成果台账，所有支撑材料都从台账反查。
3. 先准备"可被核验的事实"，再写个人叙事。
4. 答辩 PPT 只放最能支撑评审标准的证据，不堆材料。
5. 申请结束后补复盘：哪些材料最耗时，哪些可提前维护。

## 常见坑

| 坑 | 表现 | 解决办法 |
|---|---|---|
| 先写叙事后备事实 | 个人故事写得很满，但缺少可核验的成果佐证 | 先备"可被核验的事实"，再写个人叙事 |
| 答辩 PPT 堆材料 | 每页塞满论文/专利列表，评审抓不住重点 | 只放最能支撑评审标准的证据，宁少不堆 |
| 成果全文 PDF 进公开仓 | 论文 PDF 被当普通附件上传 | 学术成果只提交成果索引，全文私有 |
| 没有成果台账 | 每次申请都从头找材料，重复劳动 | 建一张成果台账，所有支撑材料从台账反查 |
| 支撑材料原件散落 | 证书/截图/通知零散存放，临交才拼 | 原件统一私有归档，公开版只记录材料类型 |

## 检查清单

- [ ] 评审办法已读，拆出评分项/硬性门槛/提交格式。
- [ ] 成果台账已建，支撑材料可反查。
- [ ] "可被核验的事实"已备齐，再动笔写个人叙事。
- [ ] 答辩 PPT 每页对应一条评审标准，未堆材料。
- [ ] 申请结束后已复盘（最耗时材料、可提前维护项）。
- [ ] 公开仓不含申请表原件/评分表/推荐意见/证书照片/论文全文。
