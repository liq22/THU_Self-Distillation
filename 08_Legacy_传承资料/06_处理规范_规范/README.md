# 处理规范中心

本目录是本 vault 的「处理规范单一真相源」：所有关于脱敏可见性、命名与模板、摄入整理流程、Git 提交的规则都收敛到这里，不在对象目录或项目页里另立第二套规范。

## 规范文件索引

| 规范文件 | 用途 |
| --- | --- |
| [[处理规范_脱敏与可见性]] | 定义哪些内容必须脱敏、`public/internal/private` 三级可见性如何判定与执行，防止敏感信息进入公开仓库。 |
| [[处理规范_命名与模板与frontmatter]] | 统一文件命名约定、模板调用方式与 frontmatter 字段标准，保证笔记结构一致、可被检索。 |
| [[处理规范_摄入与整理流程]] | 规定从 Inbox 收集到长期归档的标准流程，明确每周归档、每月复盘与收尾整理的步骤。 |
| [[处理规范_Git与提交]] | 规定提交粒度、提交信息格式、敏感内容过滤与分支策略，避免误提交未发表结果或隐私信息。 |
