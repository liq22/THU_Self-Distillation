## 6. WSL 整盘 (248 GB, **特殊情况单独处理**)

| 路径 | 大小 | 类型 | 上传? | 处理 |
|---|---:|---|---|---|
| `/mnt/e/wsl/Ubuntu20/ext4.vhdx` | 248 GB | WSL 整盘镜像 | **不上传夸克** | 单独外置硬盘备份 |

**说明**:
- 248GB 超夸克单文件 100GB 限制, 不能直接上传.
- 整盘内含敏感文件 (SSH 私钥 / .netrc / credentials.json), **绝不放云**.
- 推荐处理:
  1. **必做**: 把代码/数据通过其他途径 (rsync/git bundle/export) 上传夸克相应目录.
  2. **必做**: 敏感文件单独隔离到 USB 加密盘 (见 06_敏感文件隔离清单.md).
  3. **可选**: `wsl --shutdown && wsl --export Ubuntu20 D:\WSL_backup\Ubuntu20_20260608.tar.gz` 导出 tar.gz (压缩后 ~50-80GB), 加密后分卷 (5GB 一卷) 上传夸克 `_quarantine/WSL_backup/`.
  4. **不推荐**: 把整个 .vhdx 直接复制到外置硬盘 (单个超大文件易损坏).

**dry-run 命令**:
```bash

wsl --shutdown  # 关闭 WSL
# wsl --export Ubuntu20 <path>  # 实际导出 (耗时 1-2 小时)
```

```bash
#!/usr/bin/env bash
# 清理前备份脚本 (dry-run, 不实际执行)
# 用法: bash scripts/backup_before_cleanup_dryrun.sh

set -uo pipefail

BACKUP_ROOT="${BACKUP_ROOT:-/mnt/t/cleanup_backup_20260608}"
EXEC="${EXEC:-0}"

[[ "$EXEC" != "1" ]] && echo "[DRY-RUN] 不会实际备份. EXEC=1 后实际跑."

# 1. conda envs export
if [[ "$EXEC" == "1" ]]; then
  bash /mnt/t/A0_毕业整理_v2/scripts/export_envs.sh "$BACKUP_ROOT/_envs"
else
  echo "[DRY] bash scripts/export_envs.sh $BACKUP_ROOT/_envs"
fi

# 2. wandb 关键 run 提取
if [[ "$EXEC" == "1" ]]; then
  mkdir -p "$BACKUP_ROOT/wandb_critical"
  find /home/richie_thu/.cache/wandb -name "config.yaml" -newer /home/richie_thu/.cache/wandb/refs -print | head -50
else
  echo "[DRY] 提取 wandb 关键 run"
fi

# 3. 5_other / 迅雷下载 大文件 (>100MB) 备份清单
{
  echo "# 大文件清单 (>100MB), 清理前人工确认"
  find /mnt/k/5_other -size +100M -type f 2>/dev/null | head -30
  find /mnt/k/迅雷下载 -size +100M -type f 2>/dev/null | head -10

echo "完成. 备份根: $BACKUP_ROOT"
echo "清理前请二次确认: 99. 绝对不要删清单"
```
