## 核心价值
canonical skills 是 LQQL OS 的"agent 行为真相源" — 18 个跨场景跨项目稳定成立的 skill, 与"09_智能体开发"的方法论 + 工作流形成"方法论 → repo-local workflow → canonical skill"三层映射。每个 skill 有最小完整包 (SKILL.md + examples/prompts.md), required/optional 依赖分级, 不复制 fix 区规则 / 模板中心 / 项目骨架。
