## 核心价值

这是李奇博士期间"5 + 14"篇论文的完整科研产出闭环 (5 篇已发表 + 14 篇在审/校样)。其中:

1. **5 篇代表作构成博士论文的 5 个核心章节**: ADIG (硕士历史) / TON (第三章) / DEN (第四章) / TIFN (第五章) / Agent (第六章)。
2. **每篇论文都有完整生命周期档案**: 投稿-拒稿-重投-返修-录用-校样-发表, 包含全部 Cover Letter、Response to Reviewer、Reviewer Comments。**这种完整性在科研档案中极为罕见**, 是个人科研方法论的活教材。
3. **14 篇在投论文是未来 1-2 年的论文产出流水线**: 若全部录用, 累计 SCI 论文将达 19+ 篇, 其中 4 篇校样稿 (TII/IoT/MST/SMCA) 即将见刊。
4. **Zotero 主库 285 MB 含 2977+ 条文献元数据**: 是博士 5 年的文献检索成果, 直接复用到博后阶段可节省数百小时。

## 可复用知识

### 论文流水线方法论 (5 步法)
- 第 1 步: OneNote / drawio / xmind 起草思路 (`/mnt/d/paper/thesis/LQ/思路.drawio` + `PHD papers.xmind`)
- 第 2 步: 实验代码 (K 盘 `_Richie_project/` 与 D 盘 `10.project/`) → 实验 figure
- 第 3 步: Word 起稿 → 拒稿 → 多次返修 → 转 LaTeX (`JMS_DENpass/.git` 等含完整 git 历史)
- 第 4 步: Overleaf 协作 → 提交 → Reviewer → Response → Proof
- 第 5 步: 发表 PDF 收录到 `小论文正式版/`, txt 全文 OCR 到 `txt/` 供 OS 全文检索
