## 0. 这个仓库是什么

把 1.4 TB 的"博士四年全部产出"沉淀为:

1. **可搜索** — 442K 文件级清单 + 53K 目录级清单 (TSV/CSV), grep 即查
2. **可重现** — LaTeX 源码 + .git bundle + conda envs export + 数据集 README
3. **可上传** — 10 批上传计划, 每批配 dry-run + execute + hash_check 三脚本
4. **可沉淀** — OS 卡片 (Obsidian-friendly Markdown) + 任务导入清单 (P0/P1/P2/P3)
5. **可验收** — 每批次上传后用 hash + 文件数 + 字节大小三方校验
6. **可隔离** — 96 个敏感文件 (SSH/PEM/.env/token/证件/签名) 单独清单, 绝不上传

## 1. 严格规则 (全仓库生效, 不可关闭)

| # | 规则 | 落地位置 |
|---|---|---|
| R1 | **不自动删除任何文件** | 所有删除命令仅在 `13_执行命令建议.md §D` 中以 `rm -i` 形式给出, 且全部加 `# 禁止自动执行` 注释 |
| R2 | **不自动上传任何文件** | `scripts/copy_p0_execute.sh` 内 `USER_CONFIRMED=0`, 必须手动改 1 |
| R3 | **不读取/打印/复制敏感文件内容** | SSH/PEM/.env/token/身份证/签名只记录路径+类型+风险等级+建议, 见 `06_敏感文件隔离清单.md` |
| R4 | **所有建议必须给出理由** | 每张卡片 YAML 含 `理由:` 字段, 每个 CSV notes 列写明 "为什么上传/不上传" |
| R5 | **重复三档**: 主版本 + 备份 + 可忽略 | `05_重复文件与版本选择.md` 35 组展开 + `manifests/dedup_manifest.csv` 424 组机器可读 |
| R6 | **所有 destructive 操作必须注释 "禁止自动执行"** | 13 章 §C/§D 内每条 rm 命令前一行注释 |
| R7 | **删除命令只在"人工确认后执行"区域** | 13 章 §D 单独成节, 前置 read -p 交互确认 |
| R8 | **所有 copy/rsync 先 dry-run** | `scripts/copy_p0_dryrun.sh` + `copy_p0_execute.sh` 双件, 后者必须改 `USER_CONFIRMED=1` |

## 6. 已知限制 / 风险声明

1. **OneDrive 占位符未同步**: 309 个文件 hash 失败 (仅占位符). 上传前必须 `OneDrive --make-available-offline` 全部同步, 重新跑 Phase 2 哈希. 见 `15 §Q5`.
2. **WSL vhdx 248 GB**: 单文件超过夸克单文件 100 GB 限制, 不能直接上传, 单独备份到移动硬盘. 见 `10 §7`.
3. **ViBench 89 GB**: 接近夸克单文件上限, 建议按 h5 分 16 个文件上传. 见 `10 §1`.
4. **代码项目无 .git 远程**: 12 个项目中只有 3 个 (ViBench/7_13logic/LQQL_OS) 有 .git, 其余 9 个仅本地. 上传前最好做 git bundle. 见 `09 §总览`.
5. **Phase 3 部分 agent 中断**: 域 03 (代码) 和 域 04 (数据) 的 agent 因上下文限制中断, 后续由 Bash du/find 实测 + 续接代理补全. 09/10 章已完整, 但写作风格略有断层.
6. **签名/证件图片**: 06 章列出的身份证/学位证/签名图片均为路径, 不读取内容. 处理建议一律 "单独加密 zip, 不上传夸克".
7. **夸克客户端无 Linux 版**: 本仓库的 copy 脚本只复制到本地总仓库 `/mnt/t/博士毕业数据总仓库_202606/`, 实际"上传到夸克"需要用 Windows 上的夸克客户端拖拽 (或 rclone + webdav, 但夸克 webdav 不稳定).
