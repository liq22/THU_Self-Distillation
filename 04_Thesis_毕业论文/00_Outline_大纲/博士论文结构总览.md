# 博士论文结构总览

> 来源: OS 卡片 `013_博士论文闭环.md`(偏薄, 36 行) + `010_博士论文LaTeX源码与编译闭环.md`(详版), 经合并蒸馏
> 整理日期: 2026-07-09
> 适用范围: 清华大学机械工程系博士学位论文《面向旋转机械可解释智能诊断的神经符号网络方法研究》的章节结构、章节↔小论文映射、定稿/LaTeX 双件与审稿打磨档案导航

## 边界说明

**这页是什么**: 博士学位论文的"骨架地图"——7 章结构图 + 每章对应的已发表/在投小论文 + 定稿 PDF 与 LaTeX 源码两套交付件的定位 + 审稿打磨档案(`_reviewer_pro/`)的入口。它是论文这条线的总览页, 把 7 章合并进同一页的"章节地图", 不为每章单独建空壳页。

**这页不是什么**: 不复制论文正文内容、不内联 LaTeX 源码、不含评议书/决议书/申请书正文等敏感材料(此类只记指针)。章内实验细节、图表清单、公式推导不在本页展开——源卡片对单章没有足够的独立素材支撑独立页, 统一在本页"章节地图"小节做一句话定位。

---

## 论文一句话定位

题目《面向旋转机械可解释智能诊断的神经符号网络方法研究》, 清华学位论文模板 thuthesis, 7 章结构, 已通过答辩。核心论点不是给黑盒模型事后加解释, 而是把可解释性写入模型的参数、结构和推理流程本身; 按"理论框架 → 网络模型 → 智能体系统"三层递进展开。

## UPHMP 框架(贯穿全文的方法论锚点)

UPHMP(Unified Prognostics and Health Management Framework)7 元组是论文统一叙事的分析骨架:

`(Data, Task, Model, Loss, Domain Knowledge, Protocol, Evaluation)`

第 2 章用它建立统一语言, 第 3–6 章每个模型都可在同一 7 元组下定位, 避免章节间叙事割裂。

## 双件交付说明(定稿 PDF + LaTeX 源码)

学位论文有两套并行交付件, 缺一不可:

### 1) 定稿 PDF(成品件)

- **主 PDF**: `LQ_<学号已脱敏>_thesis.pdf`, 约 94 MB(完整版, 含全部图表)。学号嵌在文件名中, 公开引用时一律脱敏为 `LQ_<redacted>_thesis.pdf`。
- **定稿三件套**: 位于 `定稿/` 子目录, 是答辩/归档用的最终版。

> 敏感原件(学位论文全文 PDF、评议书、决议书、申请书正文等)见私有指针, 不进公开仓库。本页只记结构与指针, 不记内容。

### 2) LaTeX 源码(可重建件)

| 件 | 路径(私有指针) | 作用 |
|---|---|---|
| 编译入口 | `LQ_<redacted>_thesis.tex` (~2.6 KB) | 仅做 `\input{...}` 装配, 元信息由 `thusetup.tex` 注入 |
| 全局元信息 | `thusetup.tex` | 作者/学号/导师/题目; **清华特有, 不可重建** |
| 模板类文件 | `thuthesis.cls` | **清华特有, 不可重建** |
| 章节正文 | `data/chap01.tex` ~ `chap07.tex` | 7 章正文 |
| 摘要 | `abstract.tex` | 中英文双语单文件 |
| 个人简介 | `resume.tex` / `resume_m.tex` | 中英简介, 可填 CV |
| 参考文献(精简) | `ref/refs.bib` (~92 KB) | 编译用此份 |
| 参考文献(全量) | `ref/refs_uncited.bib` (~1.1 MB) | 保留未引用文献, 供未来回顾 |
| 答辩材料嵌入 | `committee.tex` / `resolution.tex` / `comments.tex` | 答辩委员会名单/决议/评议意见直接编译进论文, 非外置 PDF |
| 附录 prompt 工程 | `data/appendix_assets/{plan,reflect,reflector,report,execute,inquirer}_prompt.py` | 6 个脚本, 论文创新点之一的可复现证据 |
| 编译脚本 | `script/compile.sh` / `compile.bat` / `compile_lualatex.bat` | Linux latexmk / Windows / LuaLaTeX(处理中文)三件套 |
| worktree 快照 | `paper_worktree/` + `thesis-format-fix/` 分支 | 格式修复分支不污染主线 |

> **可重建性结论**: thuthesis.cls 与 thusetup.tex 一旦丢失难以重建, 是不可再生的本地配置; 其余章节 .tex / refs.bib / 编译脚本均可重新编译出 PDF。详见 [[博士论文闭环closeout]] 的"可复用知识"小节。

## 审稿打磨档案(`_reviewer_pro/`)

`_reviewer_pro/` 目录保存 v1–v5 五轮审稿意见与逐条修改记录, 是"论文打磨过程"的完整方法论档案:

- **v1–v5**: 评阅人意见 → 整体回复 → 逐条答复 → 修改说明, 五轮反复修订。
- **配套文件**: `defense_opinion_response.md`(答辩评议意见回复) + `final_revision_changelog.md`(最终修改变更日志)。
- **价值**: 审稿回复话术 + 修改追踪是后续指导师弟妹、写基金、二次投稿的核心方法论来源, 而非一次性材料。

> 评议书/决议书/申请书正文为敏感材料, 只记指针, 不进公开页。审稿打磨的方法与结构(怎么逐条回复、怎么追踪修改)可写进公开页, 具体意见原文不内联。

## 最容易卡住的地方

1. **文件名里嵌了学号**: 主 PDF / 主 .tex 文件名形如 `LQ_<学号>_thesis.{pdf,tex}`, 引用进公开仓库前必须脱敏为 `LQ_<redacted>_thesis.*`。
2. **章标题口径与任务映射不完全一致**: 源中第 3 章同时出现 TON(透明算子网络)与 TWON(透明小波算子网络)两种写法, 本页以任务指定的 TON 为主映射, 源写法在备注列保留。
3. **thuthesis.cls / thusetup.tex 不可重建**: 这是清华特有本地配置, 一旦丢失靠章节 .tex 无法复原; 备份优先级高于正文 .tex。
4. **"汇总表"和"情况简介"统计逻辑不同**: 见 [[毕业流程操作指南]], 与本页结构无关但易混。
5. **章节细节没有独立页是有意的**: 源对单章没有足够独立素材, 为 7 章各建空壳页会违反 vault 强制规则 #5(不为"体系完整"批量制造空壳页); 单章要展开时, 先在对应小论文页([[TON_透明算子网络]] 等)积累素材。
