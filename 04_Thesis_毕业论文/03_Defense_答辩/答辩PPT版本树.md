# 答辩PPT版本树

> 来源: OS 卡片 `011_答辩闭环材料清单.md`（A0_毕业整理）
> 整理日期: 2026-07-09
> 适用范围: 清华大学机械系博士答辩 + 优秀毕业生 / 学术新秀 PPT 的版本选择与归档

## 边界说明

这页是**答辩当天演示用 PPT 的版本演化树**：只记录"哪个版本做什么用、留哪个、可忽略哪个"，以及优秀毕业生 / 学术新秀这类并行申报 PPT 的版本取舍规则。

它**不是**：
- 答辩 PPT 的**内容设计**指南（讲稿与内容见 [[博士答辩讲稿]]、[[复杂度压缩推导说明]]、[[符号说明表]]）。
- 答辩当天**材料清单**（材料闭环见 [[答辩闭环材料SOP]]）。
- 评阅→答辩→申报学位的**主流程**（见 [[毕业流程操作指南]]）。

PPT / 录像等大体积资产只写**路径指针**，不内联文件。

## 一、答辩主 PPT 版本树

答辩 PPT 经历了一个典型的"从大到小、从含视频到精简主讲"的压缩迭代。核心规律：**终版不一定是文件最大或最早的，而是体积合理 + 主讲时长压到 30 分钟内的那一版**。

```
V2  (win_download, 含嵌入视频)  ──┐
V3  (飞书下载)                    ├── 早期大体积版，保留作素材备份，不作终版
V4.1 / V4.2 / V4.3 (6/1 三连发)  ──┘
        │
        ▼
V5  (6/2 最终, ~59 MB)  ◀── 答辩前定调终版
        │
        ▼
压缩包内两个推荐版本：
  · 01_主线精简压缩版_保留原答辩主线 71 页 (~46 MB)  —— 全主线保留，供完整呈现
  · 02_PPT_30分钟推荐主讲压缩版 58 页 (~38 MB)      —— 答辩当天实际主讲版
```

### 选择逻辑

| 版本 | 角色 | 处置 |
|---|---|---|
| V2 / V3 | 含视频、体积大（V2 ~114 MB）的早期版 | **可忽略**，仅作素材 / 视频源备份保留 |
| V4.1 / V4.2 / V4.3 | 6/1 一天内三次微调 | **可忽略**，已被 V5 覆盖 |
| **V5（终版 ~59 MB）** | 答辩前最终定调 | **主保留** |
| 压缩包 `01_主线精简压缩版`（71 页 / ~46 MB） | 全主线，留底 | **保留** |
| 压缩包 `02_30分钟主讲压缩版`（58 页 / ~38 MB） | 当天实际主讲 | **主保留**（答辩主讲版） |

**判断终版的两个硬指标**：
1. 文件大小合理（40–60 MB 区间，过小疑似损坏 / 过大含冗余视频）。
2. 主讲时长被压到 30 分钟内（页数 ~58 页是经验值）。

> 敏感原件（PPT 文件体、签字页）见 `98_Private_LOCAL_勿提交` 私有指针；公开页只记版本号、体积量级、页数、保留理由。

## 二、优秀毕业生申报 PPT 版本说明

优秀毕业生 PPT 与答辩 PPT 并行，但**版本选择规则不同**：取"文件名编号最大 + 修改时间最晚 + 文件大小合理"三者交集。

| 候选 | 体积 | 判定 |
|---|---|---|
| `..._李奇2.pptx` | ~41 MB | 早期含视频版，**保留作视频版备份** |
| `..._李奇3.pptx` / `_李奇4.pptx` | ~256 / 257 KB | 极小，**疑似损坏，可忽略** |
| `..._李奇6.pptx` | ~28 MB（2026-06-03） | **主版本**：编号最大 + 时间最晚 + 体积合理 |

**规则要点**：
- 文件名里嵌的编号 ≠ 修改顺序时，以**修改时间**为最终判据。
- 出现"KB 级异常小"的版本要警惕损坏，不要直接当主版本，先用体积合理的版本替代。

## 三、并行申报 PPT 一览

| 类别 | PPT | 体积量级 | 与答辩 PPT 关系 |
|---|---|---|---|
| 答辩主 PPT | V5 / 压缩包 02 主讲版 | ~38–59 MB | 主线 |
| 优秀毕业生 PPT | `..._李奇6.pptx` | ~28 MB | 与答辩 PPT 并行 |
| 学术新秀 PPT | （单独，见 [[2026_机械系学术新秀]]） | ~85 MB | 独立类别，与优秀毕业生申报并行 |

学术新秀 PPT 体积大（~85 MB），单独成类，不与答辩 / 优秀毕业生 PPT 混用一个版本树。

## 最容易卡住的地方

| 坑 | 表现 | 解决办法 |
|---|---|---|
| 终版选错 | 拿早期含视频的大版本当主讲版，现场超时 | 主讲版必须是"30 分钟压缩版"（页数 ~58、体积 <60 MB），不是体积最大的 |
| 损坏版本误用 | KB 级异常小文件被当成主版本 | 按体积合理 + 修改时间双判据，异常小版本降级为备份 |
| 优秀毕业生版本号误读 | 把文件名编号当成最终顺序 | 编号只作参考，**修改时间最晚**才是终版判据 |
| 视频源丢失 | V2 被当垃圾删了，后期想加视频却没有源 | V2（含视频）即便不主讲也保留作**素材源** |
