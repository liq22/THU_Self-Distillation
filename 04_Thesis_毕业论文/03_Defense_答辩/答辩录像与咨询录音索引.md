# 答辩录像与咨询录音索引

> 来源: OS 卡片 `007_答辩录像与学术咨询录音.md`（A0_毕业整理）
> 整理日期: 2026-07-09
> 适用范围: 博士论文打磨过程中答辩录像 + 导师/合作者咨询录音的资产索引与转写检索方法

---

## 边界说明

这页是**答辩现场录像 + 学术咨询录音这一组"不可再生音视频资产"的索引表**。它回答两个问题：(1) 这些大体积文件在哪、是什么；(2) 为什么要把无法检索的音频转成可全文检索的 SRT 字幕。

它**不是**：
- 从录音里**蒸馏出的论文修改方法论**——那是 [[论文逻辑修改要点_自SRT]]，本页只管"资产在哪、怎么找"，不管"内容说了什么"。
- 答辩当天的 **PPT 版本选择**（见 [[答辩PPT版本树]]）或**材料闭环**（见 [[答辩闭环材料SOP]]）。
- 评阅→答辩→申报学位的**主流程**（见 [[毕业流程操作指南]]）。

**脱敏 / 大体积边界**：所有音视频原件（MOV / mp4 / m4a，合计 4G+）一律只写**私有指针**，公开页只留索引（文件名、体积量级、日期、性质）+ SRT 字幕文件名。文件名里嵌的人名已脱敏（`导师咨询录音` 而非原文件名）。SRT 字幕本身可检索，但其内含的导师 / 合作者具体评价、人名讨论不进公开页——只在 [[论文逻辑修改要点_自SRT]] 里提炼**方法论**，不记评价性或隐私内容。

---

## 一、核心价值：为什么这组资产几乎不可重建

这一组资产是**博士论文打磨过程的完整证据链**，与最终的论文 PDF / 答辩 PPT 共同构成"学位闭环"：

1. **答辩现场录像** = 答辩第一手视频证据，不可再生——重新答辩一次不现实。
2. **SRT 字幕** = 把无法检索的音频转化为可全文检索的文本，是论文每章修改逻辑的可追溯记录（关键词如"第三章""图""逻辑"可直接 grep）。
3. **导师咨询录音** = 沉淀了论文之外的隐性知识：思路演进、"为什么这样改、为什么不那样写"。这类讨论在论文发表后**几乎不可能重建**——重新录一次导师咨询不现实。

> 核心判断：这类资产的价值不在"音视频字节"，而在"能否被全文检索"。未经转写的音频等于**检索盲区**，转写后的 SRT 才是可复用知识。

## 三、转写方法：把音频变成可检索知识

SRT 字幕是这组资产里**唯一进公开知识库的形态**，因为它体积小（~1 MB）且可全文检索。核心流程：

1. **转写**：用飞书 / Whisper 等工具把咨询录音（m4a / mp4）转成 SRT 字幕。
2. **归档**：SRT 文件留在私有区（含人名讨论、评价性内容），**不进公开 git**。
3. **蒸馏**：从 SRT 里提炼**方法论 / 可复用指导**（如"第三章逻辑怎么改"），写入 [[论文逻辑修改要点_自SRT]]——这是公开知识库真正要留的东西。
4. **检索**：日后写论文 / 修改论文时，直接 `grep "第三章" *.srt` 调取"为什么这样改"的依据，避免再次返工。

> 判断边界：音视频字节 → 私有指针（不进公开）；SRT 字幕 → 私有区（含隐私）；SRT 里**蒸馏出的方法论** → 公开页（[[论文逻辑修改要点_自SRT]]）。

## 最容易卡住的地方

| 坑 | 表现 | 解决办法 |
|---|---|---|
| 音频不转写就归档 | 几个 G 的 m4a/mp4 进了备份，但日后想找"导师当时怎么说的"完全检索不到 | 必须转成 SRT；未经转写的音频等于检索盲区 |
| SRT 含隐私直接进公开仓 | SRT 里的人名 / 评价性讨论被当普通文本提交 | SRT 留私有区，公开页只留文件名 + 蒸馏出的方法论 |
| 文件名嵌人名未脱敏 | 引用路径直接带导师 / 合作者姓名 | 公开页引用前替换为通用描述（"导师咨询录音"等） |
| 大体积视频误进 git | MOV / mp4 被当附件提交，撑爆仓库 | 音视频字节一律私有指针，公开页只留索引 |
| 答辩录像丢失 | PPT.MOV 被当临时文件删，后期想剪形象片无源 | 录像属不可再生资产，学位证书下发前后都不可删 |
