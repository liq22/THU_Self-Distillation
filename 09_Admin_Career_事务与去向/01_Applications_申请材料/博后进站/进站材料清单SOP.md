# 博士后进站材料清单 SOP（自动化系 2026 版）

> 来源：博士毕业源仓库 os_cards/005_博士后进站；进站材料主目录 24 文件，核心件最新修改 2026-06-08
> 整理日期：2026-07-09
> 适用范围：清华大学自动化系非定向就业博士毕业生申请本校普通博士后进站的材料清点

---

## 边界说明

这页是进站材料的**清单与核对表**，配合 [[博后进站申请流程]] 使用。它解决"进站到底要交哪些件、每一件来自哪里、是否敏感"。

不含启航奖、优秀毕业生、学术新秀、IEEE 会员证书等并行申报（这些各自有独立页或交叉链接，不在本 SOP 重复）。也不含材料的具体内容——只记清单结构、来源与脱敏边界。

流程怎么走、时间节点怎么排，见 [[博后进站申请流程]]。本页只管"清点"。

## 适合谁读

- 正在准备清华自动化系博后进站材料、需要一份逐项核对表的师弟妹。
- 不确定"哪些件是核心审核件、哪些是占位 .txt、哪些必须走私有区"的人。

## 读完能做什么

- 把 24 个进站文件按"核心审核件 / 流程模板 / 占位件 / 待确认件"四档分清，不再混装。
- 对照 Checklist 逐项打钩，确认五件套是同一天（2026-06-08）定稿的版本，签字盖章件只走私有区。
- 避开"占位 .txt 当实际上传件 / 核心件版本不同步 / 医学院流程误用"等清单层面的坑。

## Checklist（进站前逐项核对）

### 进站指南与一览表
- [ ] 通读《清华大学博士后研究人员进站指南》
- [ ] 对照 `[0]_材料一览表.pdf` 逐项确认
- [ ] 以 `[0]自动化系博士后入站流程.docx` 为院系口径（非医学院）

### 核心审核件（五件套，2026-06-08 同批定稿）
- [ ] `[1]进站审核表.doc` 已填，类别为"非定向就业"
- [ ] `[8]科研工作协议.doc` 已起草（可用整理版直接改）
- [ ] `[5]全面鉴定意见.doc` 已交导师并回收签字件
- [ ] `[6]博后住房情况调查表.doc` 已填
- [ ] `流动站单位审批意见表202109.doc` 已签流动站意见

### 支撑件
- [ ] 三方相关信息已确认（`[2]签三方相关信息.docx`）
- [ ] 入职体检已完成（参考 `入职体检指南_202401.docx`）
- [ ] 档案接收地址已确认（`档案接收地址.jpg`）

### 敏感原件（只交复印件，原件自存，私有指针）
- [ ] 学位证 / 毕业证复印件（原件私有）
- [ ] 身份证 / 户口簿复印件（原件私有）
- [ ] 博士答辩决议书复印件（原件私有，来自 [[答辩闭环材料SOP]]）
- [ ] 婚育情况证明（如需要）

### 审批与报送
- [ ] 流动站（自动化系）审批意见已签
- [ ] 由院系博后秘书报送学校博后办
- [ ] 学校审批通过，正式进站

## 敏感材料与私有指针（GitHub 上传边界）

本页进公开仓库，下列原件**绝不内联**，只在私有区记绝对路径。脱敏与可见性统一规则见 [[处理规范_脱敏与可见性]]。

- **学位证 / 毕业证**（本/硕/博）：敏感原件，见 `98_Private_LOCAL_勿提交` 私有指针
- **身份证 / 学生证 / 户口簿**：敏感原件，见私有指针
- **答辩决议书 / 学位评审通知**：敏感原件，来自学位闭环，见私有指针
- **全面鉴定意见签字件 / 进站审核表签字盖章件**：签字 / 盖章原件，见私有指针
- **成绩单（E-Transcript）**：含个人信息，进加密包，见私有指针

私有区索引：`98_Private_LOCAL_勿提交/Inbox_Raw_2026-06-16/09_Applications_Awards_Private/`

> 公开页只记**清单结构 + 来源 + 脱敏边界**，绝不记**个人证件号、签字内容、学位证正文**。

## 常见坑

| 坑 | 表现 | 解决办法 |
|---|---|---|
| 占位 .txt 当成实际上传件 | 把 `[3]/[4]/[7]/[8]` 这几个空 `.txt` 当材料上报，被退回 | 这些 `.txt` 只是清单提醒"这里要补实际材料"，本身不上报 |
| 核心件版本不同步 | 审核表用新版、鉴定意见用旧版，五件套口径不一致 | 五件套要在同一天定稿（2026-06-08 是已知最新批次），整套用同一天定稿的版本 |
| 签字盖章件误进公开仓库 | 鉴定意见、审核表的签字 / 盖章件被推进公开 git | 签字 / 盖章件含导师签字与个人信息，只走私有区 |
| 医学院流程误用 | 用医学院 8 文件流程口径填本校自动化系材料 | 医学院流程仅作参考，自动化系以 `[0]自动化系博士后入站流程.docx` 为准 |
| 待确认件盲目打包 | `三方模板1.jpg`（6.12 MB）与 `Material-1_1.sim` 未确认是否必需就塞进报送包 | 先与院系博后秘书 / 导师确认是否进站必需，再决定是否打包 |
