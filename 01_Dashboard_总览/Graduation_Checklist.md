# Graduation Checklist

## 科研归档

- [ ] 每个研究项目都有项目页
- [ ] 每个项目都有核心结论、失败记录和后续建议
- [ ] 关键代码仓库有 README
- [ ] 关键数据有来源、权限、处理流程说明
- [ ] 未发表内容已标注 `visibility: private`

## 论文归档

- [ ] 每篇论文有状态页
- [ ] 投稿、审稿、rebuttal 已整理或脱敏
- [ ] 已发表论文记录 DOI、链接、代码、数据
- [ ] 文献笔记按主题归档
- [ ] 论文流水线已闭环：见 [[论文流水线5步法]]、[[Publication_Map]]
- [ ] Response / Cover Letter 写作方法论已沉淀：见 [[Response与CoverLetter写作方法论]]
